# Minimal STACK questions for the semantics page

Moodle XML questions for the STACK question type, one per question to the
STACK author on `semantics.qmd` ("Questions requiring clarification").
The report's `_quarto.yml` copies them into the rendered site
(`resources`), so the page links them for download.

| File | Section of `semantics.qmd` |
|---|---|
| `log-square.xml` | `#log-square` |
| `decimal-tie-binary.xml` | `#rounding-teacher-tie` |
| `abs-product.xml`, `int-partial-fractions.xml` | `#abs-product` |
| `decimal-tie-rule.xml` | `#tie-rule-docs` |

They are copied unchanged (sha256 identical) from an earlier, fact-checked
reproduction, where they were checked against STACK 4.13.1
(`10d3233`) and 4.14.0 (`3338304`) with Maxima 5.46.0. They are not
graded by this repository's golden tables.
