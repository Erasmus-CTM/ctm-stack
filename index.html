STACK questions with AI Feedback

Interactive practice on Quarto teaching pages

Your answers are saved only in this browser.

Bring selected Moodle STACK questions to a teaching website. Learners practise in their browser, see how their answers are interpreted, and can request guided AI Feedback alongside the question’s mathematical grading. The exported XML, scoring rules and author tests remain available for inspection.

Quarto turns plain-text teaching material into web pages. CTM STACK adds interactive question cards to those pages for publication as a static site.

For teachers

Try a question

Expand and collect the polynomial below. An equivalent factored answer earns partial credit. Press Validate answers to inspect your expression, then Check answer to grade it. Change the variant to try fresh coefficients. The AI Feedback panel offers guided hints and explanations; it does not replace the question’s scoring. Review controls let authors replay the question’s own tests.

Expand and collect like terms: \((x+{3})(x+{4})\).

Give your answer as a polynomial in \(x\).

What is supported?

Teaching task What to try next
Equivalent algebra or a required written form Rational and form-sensitive questions
A measured number with tolerance or reported decimal places Numerical questions
Polynomial equations or Boolean propositions Equations and logic
Ordered lists, sets and nested finite collections Collection questions
A particular matrix, any basis, or a matrix meeting conditions Matrix examples and choosing an answer test
Another authored condition, such as positive definiteness Live positive-definiteness question and its authoring walkthrough

These activities cover a defined part of STACK. The authoring guide maps teaching tasks to supported tests; its developer reference records precise input, expression and grading limits. The question corpus shows which unchanged imports currently run and which need author attention.

Use your own question

  1. Export a supported question from Moodle as STACK XML.
  2. Add CTM STACK to a Quarto project and embed the named question in a page.
  3. Run its author tests, render the site and inspect an alternate correct and an incorrect answer before publishing.

The authoring guide gives the installation steps, embedding example and AI Feedback setup. For a question asking for any basis or any matrix with a chosen property, start with Python answer tests. A native Moodle STACK version of a Python-only question needs equivalent Maxima checks.

For developers

Explore the port

The existing STACK answer-test families implemented here are AlgEquiv, Sets, SameType, EqualComAss, FacForm, SingleFrac, LowestTerms, NumAbsolute, NumRelative and NumDecPlaces. The Python-only PythonChecker test uses shared matrix predicates or an author-written function for tasks such as alternate bases and matrix conditions. Ordinary response trees still control scores and feedback.
