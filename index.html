Try a STACK question on a static page

Native question exports, evaluated with SymPy in your browser

STACK SymPy reads an ordinary Moodle STACK XML export at build time. The Quarto page contains an interactive question card; a browser worker uses the same bounded Python question model to check each response. No Moodle session is needed to try these examples. The review buttons here show the authored question tests and their expected PRT outcomes.

Expand and collect

This question rewards an expanded polynomial. Try x**2+8x+15 on the first variant: this input accepts omitted multiplication signs in forms such as 8x and 2(x+1), and the preview displays the whole polynomial without extra grouping. A mathematically equivalent factored answer earns partial credit. Press Validate answers to inspect the parsed answer, then Check answer to grade it. Editing an answer requires validation again. Change the variant to see fresh coefficients.

Expand and collect like terms: \((x+5)(x+3)\).

Give your answer as a polynomial in \(x\).

How to use it in your own page

Put the XML in your project, install the extension in _extensions/stack-sympy, add filters: [stack-sympy] to _quarto.yml, and point a code block at one named question:

```{.stack-question}
#| file: questions/polynomial-expansion.xml
#| question: Expand a product (form-sensitive)
#| variants: 3
#| seed: 17
#| review: true
```

Render with quarto render, then serve the output over HTTP. The authoring guide explains the XML subset, diagnostics, grading, and the test command. The README has installation and development instructions.
