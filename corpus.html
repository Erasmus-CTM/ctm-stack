Five matrix-input problems

The four elementary-row-operation problems below run directly from unchanged official exports: row 2 plus a multiple of row 3, row 1 plus a multiple of row 3, row 2 plus a multiple of row 1, and row 1 minus a multiple of row 2. Together their original tests pass all 24 recorded seed/case combinations. Each uses a fixed 3 by 3 matrix editor and whole-matrix algebraic equivalence; no automatic cell partial credit is added.

The fifth asks learners to write a system of three linear equations as a coefficient matrix and a column vector. Its original XML is preserved unchanged and remains blocked by an unsupported inline HTML style. This explicitly attributed presentation teaching copy removes that style and closes its list; variables, answers, PRT and authored qtest are unchanged. Its original qtest passes on the first three deployed seeds. This is a presentation adaptation, not evidence that the original export runs unchanged.
