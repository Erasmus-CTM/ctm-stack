# Native STACK question corpus

These 30 original Moodle STACK XML exports come from the [STACK sample question library](https://github.com/maths/moodle-qtype_stack/tree/10d323311b7f39fb7b092dd10ce75f7d8632f525/samplequestions/stacklibrary), pinned to commit `10d323311b7f39fb7b092dd10ce75f7d8632f525`. The files are byte-for-byte copies, including CASText, CDATA, authored response trees, deployed seeds, and native `<qtest>` cases. No answer, test, or XML wrapper has been rewritten for SymPy.

The selection covers 24 Algebra Refresher questions from all 15 numbered chapters, five questions from other mathematical Topics, and one numerical-input Features example. Together they contain 73 authored qtests and 246 `<deployedseed>` entries. The [manifest](manifest.json) gives each local filename, unique local ID, exact upstream path and URL, SHA-256 checksum, original question name, topic, input count, answer-test names, qtest count, and deployed seeds. The XML itself is the authority for authored behavior.

The per-question links in the manifest identify the source and version. We have not modified the questions. This corpus excludes the upstream HELM subtree, which has a different license.

The corpus is a compatibility target, not a claim that all questions work in this limited adapter. Some exports exercise Maxima, input types, CASText, and answer tests outside the current supported subset; authored qtests also remain upstream expectations until independently run and checked. Use the recorded compatibility baseline to distinguish imports, successful qtest runs, mismatches, and explicit unsupported diagnostics. For a native XML file, run `PYTHONPATH=_extensions/stack-sympy python -m stack_sympy.cli test --file questions/corpus/AlgMap-1-6.xml` from the repository root as a quick example; this is a SymPy-adapter run, not a Moodle/Maxima differential comparison.
