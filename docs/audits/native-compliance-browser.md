## Findings

1. **Pinned fixture link is broken in preview A.** Clicking “Pinned fixture” navigated to `https://github.com/Erasmus-CTM/stack-sympy/blob/main/tests/native_compliance/fixtures.json`; GitHub showed “404 - page not found” and said `main` lacks that path. A report built from a feature commit also needs a commit-immutable source link to preserve attribution. The report owner is preparing a code-SHA link; this must be rechecked on the next deployment.
2. **Desktop filter layout uses one full-width control per row.** At a 1363px-wide browser viewport and 799px report column, the deployed `.report-controls` computed grid tracks were `799px 0px 0px`. The eight controls are functional, but require excessive vertical scrolling. The report owner traced this to Quarto wrapping the labels in one `<p>` grid child and prepared a CSS fix for the next deployment. There was no horizontal overflow (`documentElement.scrollWidth = clientWidth = 1348`, case list and controls each 799px).
